01 Robotics / Image Processing
ANEAR A unitree go1 robot that takes care of a toddler with some protocols

In this project, robot does has two important protection protocols: 1- The robot can be teleoperated from the mobile application that we have written. The mapping is also done by this mobile application. After the mapping is done, the danger zones that the parent wants to keep his/her child away are marked by the parent and these coordinates are sent to robot. While running using nav2, in the normal use case, robot uses it lidar data and constantly looks for the distance between the child and the danger zone and if some conditions are met, the the robot moves to between the danger zone and the child. It keeps the distance from the child using nav2 and local costmap inflation. 2- Robot has weights of a fine-tuned YOLOv8n. Using this, robot can detect if the child is holding a knife or a bleach. In both protocols, a push notification is send to the parent and it is logged in the database. For the robot to be interactive, there is an AI API implemented inside of it, prompted to train the toddler and play with him/her. These conversations are also logged in the database for use to monitor from its mobile application.

If wanted, robot can be teleoperated by the parent anytime. To deactivate the nav2 navigation, there is a finite state machine implementation behind the scene, both in the active blocker protocol and owner choose.

Stack: Python, C++, ROS2 Humble, OpenCV, slam, nav2, octomap, gazebo

04 DevOps / System Design
Podcast Agents A multi-agent project to generate podcasts deployed in agentcore

Project will uploaded in the github soon.

This project contains 3 collaborator agents and one supervisor agent to make podcasts from the give inputs from the frontend. The user can set characters that are going to talk and set to topic to be talked about. This is turned into a prompt for the supervisor agent that lies in the agentcore. After getting the propmt via API gateway in the AWS, the agent is using its MCP servers to make psychological analysis on the characters from the web. After setting the characters, supervisor talks to agents (using A2A that has been implemented via Strands framework) to make a script and then that script is getting turned into a mp3 file via a MCP server that uses Amazon Polly service.

Stack: agentcore cli, Python, ddgs, Strands, bedrock-agentcore, AWS services (S3, DynamoDB)

05 AI / pytorch

Developed a specialized Turkish Large Language Model to act as a mathematics tutor, utilizing Parameter-Efficient Fine-Tuning (LoRA) to generate clear, step-by-step concept explanations.
